# Ўзбекча овозли киритиш (Ovozli kiritish)

Ўзбекча гапиринг — матн курсор турган жойга ёзилади: VS Code, Claude чати, Telegram, Word — фарқи йўқ.
Интернетсиз ва бепул ишлайди (ўзбекча ўқитилган Whisper модели компютерингизда).

*Uzbek voice typing for Windows and macOS: press a hotkey, speak Uzbek, the text is typed where your cursor is. Offline, free.*

## Ишлатиш
1. Курсорни керакли жойга қўйинг.
2. **Ctrl + Alt + Space** (Mac'да **Control + Shift + Space**) — сигнал чалинади, гапиринг.
3. Яна шу клавиша — матн курсор турган жойга ёзилади. **Esc** — бекор қилиш.

Ёқиш/ўчириш — таҳрирлаш ойнасининг юқори ўнг бурчагидаги микрофон тугмаси ёки пастки панелдаги «Овоз».

## Биринчи ўрнатиш
Кенгайтма биринчи марта «Ўрнатиш»ни таклиф қилади ва терминалда ўзи қилади:
Python муҳити, кутубхоналар ва ўзбекча модел (жами ≈ 3 ГБ, бир марта, интернет керак).

Талаб:
- **Windows 10/11** ёки **macOS** (Apple Silicon — M1/M2/M3/M4) ва микрофон;
- **Python** — Windows: 3.11+, https://www.python.org/downloads/ («Add python.exe to PATH» белгиланган бўлсин);
  Mac: 3.10–3.13 (3.12 тавсия), https://www.python.org/downloads/macos/;
- Windows'да NVIDIA видеокарта бўлса — тез (1–2 сония); бўлмаса процессорда ишлайди (секинроқ). Mac'да — процессорда.

### Mac'да бир марта рухсат бериш
Тизим созламалари → **Махфийлик ва хавфсизлик**:
- **Accessibility** (Универсал доступ) — Visual Studio Code'ни ёқинг (матнни курсорга қўйиш учун);
- **Input Monitoring** (Мониторинг ввода) — Visual Studio Code'ни ёқинг (клавишани ушлаш учун);
- **Microphone** — сўралганда «Рухсат бериш».

Рухсатлардан кейин VS Code'ни қайта очинг.

## Созламалар
Ctrl+Shift+P → **Ovoz: Созламаларни очиш**:

| Калит | Маъноси |
|---|---|
| `hotkey` | Windows клавишаси (масалан `"f8"`, `"ctrl+shift+m"`) |
| `hotkey_mac` | Mac клавишаси (масалан `"ctrl+shift+space"`, `"cmd+shift+m"`) |
| `script` | `"cyrillic"` — кирилл, `"latin"` — лотин |
| `press_enter` | `true` — матндан кейин Enter ҳам босилади |
| `keep_latin` | Кириллга ўгирилмайдиган сўзлар |

Ўзгартиргандан кейин микрофон тугмаси билан ўчириб-ёқинг.

## Эслатма
- VS Code администратор ҳуқуқида очилган бўлса, дастур ҳам администратор бўлиб ишлайди — фақат шунда администратор ойналарига матн қўя олади.
- Муаммо бўлса: **Ovoz: Логни очиш**. Қайта ўрнатиш: **Ovoz: Ўрнатиш / қайта ўрнатиш**.
- Лог (`OVOZ_log.txt`) танилган матнларни сақлайди ва фақат сизнинг компютерингизда туради.
